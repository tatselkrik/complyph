## Reviewed library maintenance

ComplyPH now connects source updates to a complete local review/adoption workflow:

- Edit version-bound source metadata and record separate identity decisions with reviewer/date/basis history.
- Compare downloaded or historical references side by side, read complete sections, export exact originals and deliberately adopt, dismiss or restore a reviewed version.
- Keep affected checks held until their exact source/provision and applicability assessments are complete. Changed supporting text requires a newly implemented/tested rule profile; metadata edits never change thresholds.
- Retain reviewed legal-change holds across unrelated edits, rollback and app upgrades, with explicit audited resolution.
- Inventory qualifying issuance links from approved official publication pages, distinguish initial inventory from later links, and route citations to local source intake or rule-impact review. Links are not fetched or adopted automatically.

Revalidated findings cite the adopted source's actual hashes and include the library assessment in saved JSON/PDF reports. Earlier reports continue opening their own preserved offline sources. Recorded future effectivity and a source effective after the document's review period cannot silently activate a numeric conclusion.

The public catalog migrates from schema 4 to 5 while preserving snapshots, approvals, downloads and notes. Private schema 5 and **C:\ProgramData\ComplyPH** remain unchanged. The starter collection stays at nineteen references and the initial checking set stays at twenty comparisons across seven domains. Broader legal coverage and qualified Philippine legal review remain separate work.

Windows retains AppContainer isolation. Linux source builds add Landlock ABI 3+/seccomp confinement, protected DNS-only file access, cleared descriptors/environment and parent-death/resource guards. Unsupported kernels/platforms stay offline before any network request. The public-only HTTPS GET protocol is retained; no private document data becomes updater input. AI review remains unimplemented.

Includes synthetic listing fixtures, expanded metadata/period/confirmation/staleness/support/hold/migration tests, executable source/review/PDF preservation tests, required Linux confinement CI and six installed-Windows maintenance workflows. Discovery is bounded to approved static UTF-8 HTML pages and qualifying links; it does not promise exhaustive legal discovery or infer effectivity.

Close ComplyPH and run **ComplyPH-Setup-0.12.0.exe**, or extract the complete **ComplyPH-Windows-x64-0.12.0.zip** folder and open **ComplyPH.exe**. Keep its OCR folder. Ordinary use requires no command prompt, account, API key or subscription. The unsigned build may trigger SmartScreen. Published manifests, installation evidence and checksums identify the exact tested source and packages.
