ComplyPH can now read supported **PDF and DOCX text locally**. This release adds the private document reader and seven clearly fictional samples for trying it without providing real documents.

- **PDF:** page-numbered text and warnings for pages with no selectable text.
- **Word:** Unicode, paragraphs, table cells, tabs/line breaks, headers, footers, and notes, with original XML-part references.
- **Reader:** search, location navigation, selectable text, read again, cancellation, and friendly scan/protected/damaged-file states.
- **Privacy:** Rust readers run in a separate process with memory/CPU/time limits. Document bytes travel through local pipes; extracted text and source hashes stay in the private SQLite cache. No HTTP client, AI, telemetry, or external document-link fetching.
- **Cache and upgrades:** content hashes validate cached text on opening; changed content is read again. The private schema upgrades from 1 to 2 while retaining document entries and preferences. Removing an entry removes its cache and preserves the original.
- **Samples:** use the PDF, Word, or Scan buttons on the empty Review page. The Samples folder also includes mixed-page, protected, and damaged files and their expected results.

**This reads text; it does not assess legal compliance.** OCR, legal checking rules, reports, folder monitoring, manual source import, and daily source updates remain planned. The 14-source, seven-domain reference library is unchanged. Its known gaps and verification scope remain visible.

Close ComplyPH and run **ComplyPH-Setup-0.3.0.exe** to update. The portable ZIP can also be extracted and opened directly. Normal use requires no command prompt, Rust, Python, local AI, or paid API. Downloads are unsigned.

The Windows workflow checks the shipped executable against all seven samples, private schema migration, original preservation, fresh installation, upgrades from LaborLens PH 0.1.0 and ComplyPH 0.2.0, shortcuts, and data preservation through uninstall. Machine-readable evidence and SHA-256 checksums accompany the packages. Interactive Windows scaling remains a target-PC check; native interface testing was performed on Linux.
