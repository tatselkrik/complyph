## Desktop quality improvements

ComplyPH now adapts to smaller desktop windows and provides clearer keyboard navigation while keeping document processing local.

- Compact navigation and **Document text / Findings** tabs keep review usable down to a 640 × 480 logical client area. Passage links switch to the document and reveal the exact highlight.
- Legal provisions, document versions, library maintenance, source intake and file pickers fit the available window. Long filenames no longer expand the version-history dialog beyond the viewport.
- **Ctrl+1–5** switches sections, **Ctrl+O** chooses documents and **Ctrl+F** focuses the current search. Focus indicators, labelled edits and modal picker keyboard handling are improved.
- Document removal initially focuses **Keep document**. Enter or Escape preserves the entry unless removal is deliberately selected.
- Actual-application tests cover missing/malformed originals, local retry, unchanged historical readings/findings/reviewer actions, and late cancelled reader replies.

The Windows release gate runs twelve display-size/scaling combinations with fourteen UI scenarios each, five keyboard workflows and three recovery workflows through the installed executable. These are headless egui UI checks; physical Windows display/accessibility verification, qualified Philippine legal review and future AI evaluation remain outstanding. Roadmap #6 is partly complete.

The twenty focused checks, nineteen-reference collection and **C:\ProgramData\ComplyPH** default are unchanged. Private/public schemas remain 6/5; saved notes, issue statuses, retained readings and source-updater isolation remain in place. AI review is not included.

Close ComplyPH and run **ComplyPH-Setup-0.15.0.exe**, or extract the complete **ComplyPH-Windows-x64-0.15.0.zip** and open **ComplyPH.exe**. Keep the bundled OCR folder. Ordinary use requires no command prompt, account or subscription. The unsigned build may trigger SmartScreen.

See [desktop controls and verification limits](https://github.com/tatselkrik/complyph/blob/v0.15.0/docs/DESKTOP_QUALITY.md).
