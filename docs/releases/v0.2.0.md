ComplyPH 0.2.0 adds a bundled official reference library and renames the LaborLens PH desktop application.

- 14 official-publication snapshots across labor, DOLE OSHS, privacy/NPC, BIR/tax, SSS, PhilHealth, and Pag-IBIG.
- Local domain filters, source search, an offline text reader, search within a source, and exact-original export.
- Original bytes, source URLs, dates, applicability notes, and SHA-256 integrity checks.
- Compatibility with existing LaborLens PH document references/preferences and a preserving public-catalog migration.
- ComplyPH Windows installer, app ZIP, checksums, release manifest, library provenance manifest, and installation evidence.

For normal use, close the old app, run the installer, keep the detected installation location, and open ComplyPH from its shortcut. The app reuses an existing LaborLens PH data directory without moving live databases. Fresh installations use ComplyPH. Original documents and application data survive uninstall. No command prompt, AI model, or API key is required.

The bundled sources were checked on 16 November 2026 UTC. Verification covers official publication origin, document identity, and integrity; it does not establish complete amendments, current applicability, OCR accuracy, legal interpretation, or compliance.

Known gaps include the DOLE 2022 Labor Code edition, D.O. 252-25 and the full OSHS technical standards, Pag-IBIG Circular 460 and later remittance issuances, and complete NIRC amendments. Blocked downloads are not counted as verified. The Senate Labor Code compilation is explicitly a reference version, and the PhilHealth 2025 premium advisory remains a dated 2025 reference. See the [source inventory and notes](https://github.com/tatselkrik/laborlens-ph/blob/main/library/README.md).

Private-document extraction, legal checking, reports, watched folders, manual source import, and daily source downloads remain unimplemented. The application and catalog-status tool make no network requests.

Validation includes sixteen Rust tests, formatting, Clippy, Windows/MSVC packaging, fresh-install and v0.1.0 upgrade checks, seven-domain catalog import, shortcuts, loader startup, and preservation of synthetic private data and originals. Native interactive UI checks were performed on Linux; Windows display scaling and drag and drop remain device acceptance checks. This development build is unsigned.
