## Reviewer notes and PDF reports

Record document-review and finding notes, track Unresolved/Acknowledged/Resolved follow-up, and export a readable report entirely on your computer. Original automated findings, evidence and legal citations remain intact.

- Add a required note/reason and a self-reported reviewer name for each saved action. Corrections and reopened issues append to the local history.
- Track follow-up separately for each saved review; new reviews start fresh. Stale edits must load the latest status before saving.
- Export PDF reports with original outcomes, scope, evidence locations, legal quotations, source/rule identifiers and the complete saved reviewer history. Fonts are embedded; no printer, browser or internet is required.
- Copy a full report as JSON, including tracking history. PDF export refuses existing files and reports unsupported scripts or oversized reports explicitly.
- Upgrade private storage to schema 4 while preserving existing documents, caches, preferences and review snapshots. Windows data remains at `C:\ProgramData\ComplyPH`.

The five labour checks and 19-reference starter bundle are unchanged. A resolved follow-up status records a human action; it does not alter the automated result or certify legal compliance. Reviewer names are not authenticated signatures. Exports contain private excerpts and notes: save and share them deliberately.

### Install

Close ComplyPH, run `ComplyPH-Setup-0.8.0.exe`, and reopen the shortcut. Alternatively, extract the entire `ComplyPH-Windows-x64-0.8.0.zip` folder and open `ComplyPH.exe`. Normal use needs no command prompt, account or subscription. The Windows build is unsigned and may trigger SmartScreen. Updating/uninstalling preserves workspace data and original documents.

See [reports and tracking](https://github.com/tatselkrik/complyph/blob/v0.8.0/docs/REPORTS.md) for controls, privacy and limits. Technical verification includes local migration/concurrency tests, PDF content/pagination tests and executable workflows. The release gate additionally checks Windows installation/upgrades, installed notes/status/export, preserved review bytes and downloader isolation. `windows-install-check.json`, `release-manifest.json` and `SHA256SUMS.txt` identify the tested source and packages. Interactive Windows scaling and accessibility remain target-device checks.
