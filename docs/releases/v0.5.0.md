# ComplyPH 0.5.0 — Local legal sources

Add your own public legal references to the offline library from **Legal library → Add legal source**.

- Import local PDF/DOCX files with their title, instrument number, issuing agency, official HTTPS citation, compliance domains, issue/effective dates and notes.
- Preview extracted text and preserve the original reference and reading text with integrity hashes. The bounded local reader keeps intake responsive and rejects unreadable/protected/scanned-only files without a partial catalog entry.
- Distinguish **Awaiting verification** from **Identity checked by me**. A user-recorded comparison never becomes a verified agency download or activates an automated checking rule.
- Preserve earlier versions when a changed file is imported under the same URL. Identical bytes retain the original recorded metadata. Bundled references and existing report source pins cannot be replaced through manual intake.
- Migrate the public catalog to schema 3 while retaining existing sources. Private workspace schema 3 and `C:\ProgramData\ComplyPH` storage remain unchanged.
- Update installation/source-intake documentation and replace the outdated version text in the README banner with a version-independent label. The version badge and download links identify this release.

Close ComplyPH before running the installer. The installer preserves the existing workspace, imported references and original documents. The portable ZIP opens without a command prompt. Packages include checksums and machine-readable Windows install/import verification evidence.

The bundled collection still contains 19 references in seven domains. Automated review remains limited to three focused labour checks. Automatic daily source updates, watched folders and in-app OCR remain planned. Windows binaries are unsigned and may trigger SmartScreen.
