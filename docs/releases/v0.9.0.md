## Local OCR and folder intake

Recognize scanned PDFs on your PC and optionally pick up completed PDF/DOCX files from a chosen local folder. The Windows installer/ZIP includes the OCR runtime, English recognition data and component licences. No OCR service, subscription, document upload or separate setup command is required.

- **Run local OCR** recognizes every PDF page, retains physical page numbers and flags low-confidence words. Confidence does not prove accuracy; compare every page and number with the original.
- Numeric checks require a separate OCR accuracy confirmation as well as the existing scope/operative-term confirmation. Incomplete pages and unsupported recognition metadata remain unresolved. Rule engine 3 adds this input gate; the five labour thresholds and starter legal bundle are unchanged.
- **Settings → Watched document folder** enables optional nonrecursive intake while the app is open. It waits for quiet writes/completion markers, handles writer locks, skips temporary files/links and avoids unchanged/duplicate content. A pause control and **Forget folder and intake history** are available.
- Folder intake adds document entries only. It never starts OCR/reviews, infers coverage or sends anything to AI. Open documents to inspect reading accuracy and establish scope deliberately.
- Private schema 5 preserves documents, caches, historical reviews and reviewer actions while adding local intake configuration/history. The workspace remains at `C:\ProgramData\ComplyPH`.

OCR limits are 20 PDF pages, 32 MiB input, 4 MiB text, a 2,800-pixel maximum page side, 90 worker CPU seconds and 120 elapsed seconds. English OCR can miss handwriting, poor scans, tables and other scripts. Original PDFs are unchanged; no searchable-PDF rewriting is performed. Public source intake still requires selectable text. A watched-folder quiet interval reduces partial imports but cannot guarantee another program will never resume writing later.

### Install

Close ComplyPH, run `ComplyPH-Setup-0.9.0.exe`, then reopen its shortcut. Alternatively, extract the complete `ComplyPH-Windows-x64-0.9.0.zip` folder and open `ComplyPH.exe`; keep its `OCR` folder. The build is unsigned and may trigger SmartScreen. Updates/uninstall preserve workspace data and originals; only known bundled runtime files are removed.

See [OCR and folder controls, privacy and limits](https://github.com/tatselkrik/complyph/blob/v0.9.0/docs/OCR_AND_FOLDERS.md). The release gate checks actual installed OCR/provenance on three synthetic fixtures, confirmation gates, partial/duplicate folder intake without automatic reviews, earlier reports/tracking, upgrades, preservation and downloader isolation. Manifests/checksums identify the exact tested source and packages. Interactive Windows scaling/accessibility remain target-device checks; technical tests do not certify legal compliance or OCR accuracy.
