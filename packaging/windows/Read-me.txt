ComplyPH 0.3.0 - Local document reader
Formerly LaborLens PH

Close ComplyPH or LaborLens PH before installing. Keep the detected installation
location when upgrading. Open ComplyPH from its desktop/Start menu shortcut,
or extract the app ZIP and open ComplyPH.exe. Normal use needs no command prompt,
Rust installation, Python, browser session, AI model, API key, or subscription.

Available:
- Navy-and-cream native Rust workspace.
- Read supported PDF and DOCX text locally, without changing originals.
- PDF page references; Word paragraph/table/part references; text search.
- Private local text cache; content hashes checked when reopening a document.
- Friendly states for scans, password protection, damaged files, and limits.
- Seven synthetic reader cases in Samples; PDF/Word/Scan sample buttons in-app.
- Browse 14 official publication snapshots across seven compliance domains.
- Source filters, offline reading/search, original export, dates, and SHA-256 checks.

The reader does not send document content online. It does not run Word fields,
macros, embedded programs, PDF JavaScript, or external document links. Read text
can omit images, text boxes, annotations, and deleted text, or lose table/layout
order. Compare it with the original. OCR is not included. Reader limits: 32 MiB
input, 300 PDF pages, 4 MiB text, and a 20-second worker timeout.

Use Review > Try a synthetic sample, or Choose document. Originals stay in place.
Removing an entry removes its cached text too; it does not delete the original.
All samples are fictional test data, not legal templates.

"Verified" sources concern official origin, identity, and content integrity.
The starter collection has documented gaps. Legal checking, reports, watched
folders, manual source import, and daily updates are not implemented yet.

New Windows data:
%LOCALAPPDATA%\ComplyPH\private\workspace.sqlite3
%LOCALAPPDATA%\ComplyPH\library\catalog.sqlite3

An existing %LOCALAPPDATA%\LaborLens PH data root is reused without moving live
databases. Existing references/preferences are retained while the private schema
upgrades to version 2 for text caches. Uninstall preserves all application data
and original documents. SQLite storage is not encrypted by the application.
