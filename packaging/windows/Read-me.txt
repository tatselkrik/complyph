ComplyPH 0.2.0 — Official source library
Formerly LaborLens PH

Close LaborLens PH or ComplyPH before installing. Keep the detected installation
location when upgrading. Open ComplyPH from its desktop/Start menu shortcut,
or extract the app ZIP and open ComplyPH.exe. Normal use needs no command prompt,
Rust installation, browser session, AI model, or API key.

Available:
- Navy-and-cream native Rust workspace.
- Register local PDF/DOCX references, search metadata, and save preferences.
- Browse 14 official publication snapshots across seven compliance domains.
- Filter/search sources, read local text, search within a source, and save originals.
- Source URLs, provenance, dates, applicability notes, and SHA-256 checks.

"Verified" concerns official origin, document identity, and preserved-content
integrity. This is a starter collection with documented gaps, not a complete
current legal corpus. OCR and table layouts may be imperfect; use originals.

Open Legal library to inspect the collection. Library-notes.md and
starter-manifest.json describe the included sources and missing acquisitions.

Private document text extraction, legal checking, reports, folder monitoring,
manual source import, and daily downloads are not implemented yet.
Selecting a private document stores metadata only and does not upload, copy,
or modify it. Samples contains synthetic files, not legal templates.

New Windows data:
%LOCALAPPDATA%\ComplyPH\private\workspace.sqlite3
%LOCALAPPDATA%\ComplyPH\library\catalog.sqlite3

An existing %LOCALAPPDATA%\LaborLens PH data root is reused without moving
databases. If both branded roots exist, the app preserves both and requires
explicit workspace selection. Uninstalling preserves data and original documents.
